# 기술 메모 (드래곤퀘스트 VIII 하늘과 바다와 대지와 저주받은 공주, PS2 SLPM-65888)

## 파일 구조
| 항목 | 위치 | 형식 / 처리 |
|---|---|---|
| 파일 색인 | `DATA.HD6` | 문자열 조각 풀 + 이름 레코드(조각 번호 1~2바이트) + 엔트리 8바이트(u16 이름, u24 오프셋, u24 크기). 오프셋 = (필드 & ~1) × 0x200, **bit0은 플래그**, 크기 = 필드 × 16 (`tools/dq8arc.py`) |
| 데이터 | `DATA.DAT` (약 1.98GB) | 커진 파일은 끝에 덧붙이고 뒤의 `DMYDATA`(더미) 영역을 줄임 (`tools/isopatch.py`) |
| 청크 팩 | `.pak` `.pac` | 항목마다 0x50 헤더(이름, u32 0x50, 데이터 크기, 전체 크기) + 데이터, 크기 0xFFFFFFFF로 끝 (`formats.Pak`) |
| 이벤트 대사 | `event\e*\*.txt` | `@ID` + SJIS 본문, 실행 중 폰트표로 변환 |
| 마을·동료 대화·메뉴 | `.mes` / 동료 대화 `.bin` | u16 개수, u16 끝 위치, (id, 오프셋) 표, 폰트표 번호로 미리 인코딩(0xFF00 줄바꿈, 0xFF01 끝, 0xF000 이상 제어코드). 파일마다 l3/s3 중 한 표를 씀 (`translation/mes_fonts.tsv`) |
| 문자열 표 | `.str` | u32 개수 + 12바이트 + (u32 id, u32 오프셋) + SJIS NUL 문자열 |
| 전투 텍스트 | `bin\bin_ext.pak` | `actmsg_text_2.txt` 등 따옴표 스크립트, 몬스터 파라미터(128바이트 레코드, 이름 +0x10 32바이트), 배회 몬스터(16바이트 레코드) |
| 맵 스크립트 | `map\**\*.stb` | 조사·보물상자 메시지가 SJIS로 박혀 있음. 모션 라벨과 섞여 있어 문장만 제자리 교체 |
| 책 | `event\book\bookmes.txt`, `bin_ext\bookmes.txt` | 이벤트 txt 형식, 줄바꿈 LF |
| 세이브 화면 | `menu\mcard2.pak` | `mcstring.str`(0x60바이트 고정 칸), `mcstrlist.bin`(장 이름 0x20바이트) |
| 실행파일 | `SLPM_658.88` | 예/아니요, 파티 기본 이름, 개수 단위, 이름 입력 문자판(0x290430~)과 명령 비교 문자열(0x2A61F8~) |

## 글꼴
- **대화창 글꼴** `meswin\font_tex_l3s3.pak` + `meswin\fonttbl_l3.bin` / `fonttbl_s3.bin`
  - 폰트표: u16 ASCII 수(88), u16 비한자 수, u32 전체 수, 이후 빅엔디언 SJIS 코드 정렬 목록. 게임이 이진 탐색으로 찾고, 번호 i = 텍스처 칸 i.
  - 표는 4KB 버퍼에 읽힘(`slti v0,4097`, 0x2EFDD8) → **최대 2,044자**.
  - 칸 18×22, 한 줄 28칸, 17줄. l3는 2bpp 6면(4bpp 텍스처 3장에 두 면씩), s3는 4bpp 3장(1,428칸).
  - 표의 ASCII 구간(앞 88자) 글자는 항상 반각 9px(0x2EE118). 0x20은 건너뛰므로 번역문 공백은 빈 `_` 글리프로 넣음.
- **메뉴 창 글꼴** `font16.img` 외 3벌: IM3(TIM2 4bpp 1024×1024 두 장), JIS 순서 16×16, 한 줄 64자.

## 한글 방식
- KS X 1001 한글 2,350자를 SJIS 한자 코드 0x889F부터 순서대로 대응(`translation/charmap.json`).
- 폰트표에는 번역에 실제로 쓰인 한글만 넣음(대화 1,369자 / 메뉴 1,109자). 메뉴 표가 넘치면 대화 쪽 글자를 빈도순으로 잘라 냄.
- 번역되지 않은 일본어의 한자는 ■로 바꿔 표에 없는 코드가 생기지 않게 함.
- 글꼴은 NanumSquare Neo Bold(cBd). 원본 획 두께(약 1.65px)를 재어 Regular/Bold를 비교해 고름.
